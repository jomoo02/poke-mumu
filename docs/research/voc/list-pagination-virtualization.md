## 경쟁 사이트 기대치

- **Pokémon Database `/pokedex/all`:** 전체 포켓몬을 한 페이지에 모두 그린다. 페이지 나누기도 가상화도 없다. 머리글로 정렬하고 위 입력창으로 검색한다.
  - [pokemondb.net/pokedex/all](https://pokemondb.net/pokedex/all)
- **Serebii, Bulbapedia:** 세대별 또는 전체 목록을 긴 한 페이지로 보여 준다.
- **결론:** 포켓몬 사이트 사용자에게 익숙한 것은 "한 페이지에 다 있고, 스크롤과 Ctrl+F로 찾는" 형태다.

## 참고: 가상 스크롤은 무한 스크롤과 다르다

poke-mumu의 가상 스크롤은 데이터를 모두 받은 상태에서 그리기만 줄인다. 그래서 NN/g가 지적한 무한 스크롤 문제 중 일부는 해당하지 않는다.

- 해당하지 않음:
  - 푸터 접근 불가 (전체 높이가 미리 잡힘)
  - 끝이 안 보이는 착각 (결과 수를 표시함)
  - 추가 로딩 대기
- 남는 문제:
  - 돌아올 때 위치 복원
  - Ctrl+F
  - 검색엔진 수집: 서버 HTML에는 처음 화면 몇 줄만 들어간다. 이 사이트는 sitemap이 없어 목록이 상세 페이지로 가는 주요 링크 경로다.
  - 스크린리더가 화면 밖 줄을 모른다 (aria-rowcount로 일부 보완)

## poke-mumu 기회

1. 상세 화면에서 돌아올 때 위치 그대로 (불만 #1, #2)
2. Ctrl+F로 목록 전체 찾기. 포켓몬 사이트 사용자의 기존 습관에 맞음 (불만 #3)
3. 능력치 순위를 끊김 없이 훑기. 페이지를 넘기지 않고 (sort-ui.md 시나리오 1·2)
