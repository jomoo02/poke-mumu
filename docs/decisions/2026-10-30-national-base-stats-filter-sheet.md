# 전국도감 종족값: 통합 필터 시트 + 적용 칩 (2026-10-30)

> 2026-10-30에 바뀜: 통합 시트를 버리고 묶음별 필터로 → `2026-10-30-table-page-toolbar.md`

`/pokedex/national-base-stats` (`_pages/pokedex/national-base-stats-final`).
`2026-10-28-national-base-stats-layout.md`의 "툴바" 결정을 바꾼다 (그때 버린 R2 적용 필터 줄, C 필터 버튼 하나로 묶기를 다시 택한다).
같은 문서의 "지연 렌더를 뺀다"도 바꾼다 (아래 "검색 입력").

## 선택

### 툴바
```
lg 미만: [한국어⌄  이름·도감번호 검색   ✕ 🔍] [⚙²]
         [불꽃 ✕] [1세대 ✕] ↻ 초기화              ← 켜진 게 있을 때만
lg 이상: [한국어⌄  이름·도감번호 검색   ✕ 🔍] [⚙ 필터 2]          12 Pokémon
         [불꽃 ✕] [1세대 ✕] ↻ 초기화
```
- **이름 표기는 검색창 안 앞쪽.** 검색 언어(·이름 표시·이름순 정렬)를 정하는 값이라 필터와 섞지 않는다.
  배경·호버 효과 없이 글자 + ⌄, 기본값(한국어)이 아니면 글자만 강조. 구분선 없음.
- **돋보기는 검색창 오른쪽 끝**, 입력값이 있으면 그 왼쪽에 ✕.
- **필터는 버튼 하나 → 통합 시트.** 타입·모습·세대를 탭 없이 차례로(스크롤), 묶음 제목 줄은 sticky + 묶음별 초기화.
  아래 줄 [초기화(필터만)] [N마리 보기(닫기)]. 고르는 즉시 반영.
  - lg 이상 오른쪽 시트(448px), 미만 바텀시트(85dvh). 목록은 모두 2열(타입도 2열), 줄 높이 44px.
  - lg 미만 버튼은 아이콘 + 선택 수 배지, 이상은 '필터 2'.
- **적용 칩 줄.** 켜진 필터 값마다 칩(✕로 끔), 끝에 초기화(필터만. `2026-10-30-national-base-stats-reset-scope.md`). 켜진 게 없으면 줄이 없다.
  초기화 위치 문제(필터 버튼을 밀어냄)가 여기서 없어진다.

### 검색 입력
- 결과 계산 조건을 `useDeferredValue`로 늦추고 카드·표 행은 `memo`. 입력창은 바로 바뀌고 목록은 뒤에서 다시 그린다
  (한 페이지 카드 + 표 최대 200행을 키마다 동기로 그려 지울 때 버벅였다).

## 비교 (묶음별 트리거 v1 ↔ 통합 시트 v2, 같은 페이지 두 경로로 비교)
| 기준 | v1 | v2 |
|---|---|---|
| 모바일 툴바 | 2줄 고정, 375px에서 필터 줄 가로 넘침 | 1줄 + 켜졌을 때만 칩 줄 |
| 켜진 조건 | 버튼 글자 '불꽃 +1' | 칩에 모든 값, 하나씩 끔 |
| 초기화 | 나타나면 필터 버튼을 민다 | 칩 줄 끝 |
| 필터 하나만 바꾸기 | 한 번에 그 묶음 | 시트 열고 스크롤 |
| 무엇으로 거르는지 | 버튼 글자로 보임 | 모바일은 아이콘 |

## 받아들인 대가
- 모바일 필터 버튼이 아이콘뿐이라 처음 온 사용자가 놓칠 수 있다 (필터 아이콘 관례에 기댄다).
- 필터 하나만 바꿀 때도 시트를 열고, 세대는 시트 맨 아래까지 스크롤한다.
- 데스크탑 시트 배경(공용 Sheet의 흐림)이 목록을 덮어, 고르는 동안 결과 변화가 안 보인다.
- 데스크탑도 넓은 공간에 버튼 대신 시트를 연다 (혼합안: 데스크탑만 묶음별 팝오버 + 칩도 검토했다).

## 버린 안
| 안 | 버린 이유 |
|---|---|
| 시트 안 탭(묶음마다) | 묶음이 3개·선택지 약 35개라 한 번 스크롤로 끝난다. 탭은 다른 묶음의 선택을 가린다 |
| 데스크탑 가운데 모달 / 모바일 풀 화면 | 모달은 목록을 가리고, 풀 화면은 페이지 이동처럼 느껴진다 |
| 혼합안 (lg 미만 v2, 이상 묶음별 팝오버 + 칩) | 두 배치를 유지하는 비용 대신 한 가지로 통일 |
| 이름 표기를 시트 안 '표시' 칸으로 | 검색창은 밖인데 검색 언어를 시트에서 바꿔야 하고, 시트 초기화 범위가 애매해진다 |
| 결과 수를 툴바에서 빼 표 위 결과 줄로 (`[검색][필터]` / `N Pokémon` / 표) | 2026-10-30 적용해 봤다가 되돌림. 데스크톱 결과 줄이 개수 하나뿐이라 허전하고, 툴바가 더 비어 보였다 |
| 필터를 오른쪽 끝으로 `[검색][개수] … [필터]` | 필터 버튼과 칩·초기화가 양 끝으로 갈리고, 입력 사이에 결과 수가 낀다 (조사: `docs/research/voc/base-stats-toolbar.md` 10-30 추가분) |
