# 전국도감 종족값: 툴바 배치 · 페이지네이션 · 표/카드 분리 (2026-10-28)

> 툴바·지연 렌더 결정은 `2026-10-30-national-base-stats-filter-sheet.md`로 바뀌었다.

`/pokedex/national-base-stats`. 아래 결정을 바꾼다.
- `2026-10-19-list-rendering.md`의 "페이지네이션 없이 전부 그리기"
- `2026-10-20-mobile-sort-sheet-virtualization.md`의 "좁은 본문 가상화 · 넓은 본문 전부 그리기"
- `2026-10-23-national-base-stats-filter.md`의 화면·초기화 위치

## 선택

### 툴바
- 좁은 본문 (모바일과 같다):
  ```
  [🔍 검색                      ]
  [↻ 초기화 │ 한국어⌄ 타입⌄ 모습⌄ 세대⌄ ···]   ← 줄 전체가 가로 스크롤
  1,250 Pokémon            [정렬⌄]
  ```
- 넓은 본문 (`@5xl/view`, 본문 1024px 이상):
  ```
  [🔍 검색] [↻ 초기화 │ 한국어⌄ 타입⌄ 모습⌄ 세대⌄]          1,250 Pokémon
  ```
  결과 줄은 숨긴다 (개수는 툴바 끝, 정렬은 표 머리글).
- 초기화는 두 본문 모두 **검색과 필터 묶음 사이(필터 줄 맨 앞)**. 켜진 조건이 있을 때만 글자와 함께 보인다.
  - 나타나면 필터 버튼이 오른쪽으로 약 100px 밀린다. 받아들였다: 글자가 있어 뜻이 분명하고,
    데스크탑에선 필터 바로 옆이라 손이 멀리 가지 않는다. 두 본문의 위치 규칙도 같다.
  - 처음엔 R3(필터 줄 오른쪽 끝, 좁은 본문은 ↻ 아이콘만 고정)로 정했다가 v2 비교 화면을 보고 바꿨다.

### 페이지네이션 (70개)
- 좁은·넓은 본문 모두. 기술·특성 목록과 같은 크기·같은 `PaginationNav`.
- 검색어·필터·정렬·이름 언어·초기화가 바뀌면 1페이지로 (언어는 이름순 정렬·검색 결과를 바꾼다).
- 지연 렌더(`useDeferredValue`)·가상화·`content-visibility`를 뺀다.

### 표 / 카드 분리
- 넓은 본문 = `ui/stat-table` (11칸 grid, 머리글 정렬), 좁은 본문 = `ui/stat-cards` (2줄 카드).
- 둘 다 그리고 본문 폭(`@5xl`)으로 하나만 보인다. 70줄 × 2벌이라 DOM 부담이 작고, JS 폭 판정의 첫 렌더 깜빡임이 없다.
- 능력치 순서·라벨은 `model/base-stats-poke`의 `STAT_KEYS`·`STAT_LABEL`·`STAT_SHORT_LABEL` 하나를 함께 읽는다.

## 받아들인 대가
- 브라우저 찾기(Ctrl+F)는 현재 페이지 안에서만 된다. 검색창으로 대신한다.
- 능력치 순위를 페이지를 넘기지 않고 끝까지 훑을 수 없다. 정렬하면 1페이지라 상위권은 바로 보인다.

## 이유
- 실기기에서 전체 그리기(모바일은 가상화 이전)·가끔 데스크탑에서도 정렬이 크게 늦는 순간이 남았다.
- 한 벌의 요소를 `display: contents`로 두 레이아웃에 쓰는 구조가 복잡해 고치기 어려웠다.

## 버린 안 (툴바)
| 안 | 버린 이유 |
|---|---|
| R3: 필터 줄 오른쪽 끝 (좁은 본문 ↻ 아이콘 고정, 넓은 본문 `[↻ 초기화] \| 개수`) | 버튼은 안 밀리지만 아이콘만으로는 뜻이 약하고, 데스크탑에선 필터와 멀다. 비교 화면에서 사이 배치가 낫다고 판단 |
| R1: 결과 줄 `개수 … [↻ 초기화] \| [정렬]` | 모바일 결과 줄이 너무 빽빽하다 |
| R2: 적용 필터 줄(칩 + 초기화) 추가 | 첫 필터에 목록이 한 줄 밀린다. 버튼 글자와 칩에 값이 두 번 나온다. 데스크탑에도 줄이 필요하다 |
| C: 모바일 '필터' 버튼 하나로 묶기 | 켜진 필터가 안 보인다. 10-23의 '그룹마다 따로' 결정과 어긋난다 |
| 이름 언어를 결과 줄로 | 모바일은 지금 형태를 유지하기로 했다 |

## 검토한 반박
- 첫 필터를 켜면 버튼이 손가락 아래에서 밀린다 (연달아 고를 때 다른 버튼을 누를 수 있다): 받아들였다.
  필터는 시트·팝오버로 열고 닫으므로 연속 탭 사이에 시선이 다시 버튼 줄로 돌아온다.
- 좁은 본문 375px에서 '모습'부터 화면 밖으로 넘어간다: 줄이 가로 스크롤이라 닿을 수 있다.
