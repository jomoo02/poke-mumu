# 표 페이지 툴바: 검색 + 묶음별 필터 (2026-10-30)

첫 적용: `/pokedex/national-base-stats` (`_pages/pokedex/national-base-stats-final`).
검색·필터가 있는 표 페이지는 이 패턴을 쓴다.
`2026-10-30-national-base-stats-filter-sheet.md`(통합 필터 시트 + 칩)를 바꾼다.

## 선택
```
lg 이상: [한국어⌄ 검색 (w-80)] [타입⌄] [모습⌄] [세대⌄] 모두 지우기          1,248 Pokémon
         ┌ 표 ┐
lg 미만: [한국어⌄ 검색 ─────────── 🔍]
         [타입⌄] [모습⌄] [세대⌄] 모두 지우기     ← 가로 스크롤, 묶음마다 바텀시트
         1,248 Pokémon               도감번호순⌄  ← 결과 줄
```
- **검색은 필터와 같은 줄 맨 앞, 고정 폭.** 트리거가 바로 뒤에 붙어 "목록 조건" 한 덩어리로 읽힌다.
- **필터는 묶음마다 트리거.** 트리거 글자가 고른 값을 보여 준다(`불꽃 +1`), 칩 줄 없음.
  - 데스크톱 팝오버는 1열 목록, 높이 max-h-80 (`FilterCheckboxControl popoverLayout="list"`).
- **모두 지우기(필터만)는 트리거 뒤.** 켜졌을 때만, 나타나도 트리거가 밀리지 않는다.
- **개수는 줄 오른쪽 끝**(데스크톱), 결과 줄(모바일). 정렬은 데스크톱 표 머리글, 모바일 결과 줄.
- 툴바가 한 줄이라 필터를 켜고 꺼도 표가 움직이지 않는다.

## 데스크톱 ↔ 모바일 규칙
| 데스크톱 | 모바일 |
|---|---|
| 묶음별 팝오버 | 묶음별 바텀시트 (통합 시트 없음) |
| 통합 시트 | 통합 시트 |

데스크톱과 모바일이 같은 멘탈 모델(묶음 단위 / 한 번에)을 쓴다. 섞지 않는다.
모바일 필터 줄이 넘쳐 가로 스크롤되는 것은 받아들인다.

## 버린 안 (모두 같은 날 화면으로 비교)
| 안 | 버린 이유 |
|---|---|
| 통합 시트 + 칩 (`[검색] … [⚙ 필터]`, 칩 줄) | 데스크톱에서 개수 둘 곳이 없고(툴바 끝·결과 줄·표 아래 모두 시도), 필터 하나 바꿀 때도 시트를 열고 표를 가린다 |
| 검색 혼자 한 줄 (전체 폭 / w-1/2 / max-w) | 전체 폭은 너무 길고, 좁히면 검색이 필터와 따로 논다. 사례상 필터를 접어 두는 "도감 찾기" 화면의 배치 |
| 검색을 제목 줄 오른쪽 끝 | 검색이 목록 조건이 아니라 사이트 검색처럼 읽힌다. 제목과 떨어뜨린 사례 없음. 공용 `PageLayoutHeader`에 자리를 새로 만들어야 한다 |
| 필터 버튼을 오른쪽 끝 / 개수와 묶기 (A·B·D) | 버튼과 결과(칩)가 갈리거나, 검색 뒤에 떠 있어 기준선이 없었다 |
