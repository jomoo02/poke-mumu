# 전국도감 종족값 필터 (2026-10-23)

## 결정

### 필터 목록
- 타입 · 모습 · 세대. 그룹 안: 타입 AND(최대 2개), 모습·세대 OR. 그룹 사이 AND
- 모습 선택지는 /pokedex/national과 같다: 메가진화 · 알로라의 모습 · 가라르의 모습 · 히스이의 모습 · 팔데아의 모습 (정식 명칭, 소제목 없음)
- 세대(1~9)는 `poke.generation`. 폼(generation null)은 세대를 고르면 빠진다 (national과 같음).
  배포 후 사용 경험을 보고 '같은 종의 기본 모습 세대를 따른다'로 바꿀지 다시 판단한다

### 모습 데이터: `form.kind` + `form.region`
- `kind`: mega · primal · regional · other (필요해지면 other를 나눈다)
- `region`: alola · galar · hisui · paldea · null (zen-galar → galar, paldea-* → paldea)
- 버린 안
  - identifier 토큰 일치(national): 필터의 뜻이 이름 규칙에 숨어, 규칙과 다른 새 폼이 조용히 빠진다
  - 열 하나(`filter_key`): 종류와 지역이 섞여 '리전폼 전체' 같은 묶음에 다시 대응표가 필요하다

### URL
- 한 키에 `그룹.값`: `?filter=type.fire_form.alola_gen.1` (고른 순서 유지)
- 값은 DB 열 이름이 아닌 선택지 값. 열 구조가 바뀌어도 공유 링크가 그대로 동작한다

### 화면
- 검색창은 입력만. 그 아래 한 줄(모바일·데스크탑 모두, 가로 스크롤):
  `[↻ 초기화] │ [이름 언어] [타입] [모습] [세대]`
- 각 버튼은 md 이상 팝오버, md 미만 시트 (그룹마다 따로, 탭 없음)
- 선택지는 모두 체크박스 (national과 비슷하게). 타입은 아이콘 + 이름 3열, 모습 1열
- 체크박스 목록·그룹 하나짜리 시트는 `_shared/ui/filter`에 추가한다 (기존 타일 방식은 그대로 둔다)
- 이름 언어도 필터 줄에 둔다: 필터와 같은 방식(팝오버·시트)으로 동작하고 초기화를 한 번에 하기 위해

### 초기화
- 검색어 · 이름 언어 · 필터를 한 번에 지운다 (정렬은 결과 줄의 보기 설정이라 두고)
- 하나라도 켜져 있으면 줄 맨 앞에 보인다 (맨 뒤면 모바일에서 스크롤해야 보인다)
- 누르면 버튼이 사라지므로 포커스를 검색 입력창으로
- 검토한 반박: 언어만 되돌리면 영어 검색어가 남아 0건이 된다 → 검색어까지 지워 해결
