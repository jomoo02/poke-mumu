# 전국도감 종족값 필터 (2026-10-23)

## 결정

### 필터 목록
- 타입 · 모습 · 세대. 그룹 안: 타입 AND(최대 2개), 모습·세대 OR. 그룹 사이 AND
- 모습 선택지는 /pokedex/national과 같다: 메가진화 · 알로라의 모습 · 가라르의 모습 · 히스이의 모습 · 팔데아의 모습 (정식 명칭, 소제목 없음)
- 세대(1~9)는 `poke.generation`. 폼(generation null)은 세대를 고르면 빠진다 (national과 같음).
  배포 후 사용 경험을 보고 '같은 종의 기본 모습 세대를 따른다'로 바꿀지 다시 판단한다

### 모습 데이터: `form_group` 테이블 (2026-10-26 변경)
- 선택지를 데이터로 관리한다: `form_group(identifier, name_ko, name_en, name_ja, sort_order)` + `form.form_group_id`
  (null이면 모습 필터에 안 잡힘. zen-galar → galar, paldea-* → paldea)
- 라벨은 form의 정식 명칭에서 복사했다 (메가진화 · 알로라의 모습 …, 영·일 포함 → 필터 라벨을 이름 언어에 맞출 수 있다)
- 선택지 추가·라벨·순서 변경은 데이터만 바꾼다 (코드·마이그레이션 없음. 조회가 'use cache'라 캐시 갱신은 필요)
- 버린 안
  - identifier 토큰 일치(national): 필터의 뜻이 이름 규칙에 숨어, 규칙과 다른 새 폼이 조용히 빠진다
  - 열 하나(`filter_key`): 종류와 지역이 섞여 '리전폼 전체' 같은 묶음에 다시 대응표가 필요하다
  - `kind` + `region` (text+check → enum, 2026-10-23 적용 후 되돌림): 허용 값은 한 곳(enum)에서 정해지지만
    라벨이 코드에 남고 언어별 라벨을 코드 상수로 관리해야 한다
- 대가: TS 타입이 string(유니온 아님), URL 검증·필터가 서버에서 받은 선택지 목록에 의존한다
- 위치: 지금은 이 페이지(`model/form-group.ts`, `api` getFormGroups). /pokedex/national을 `_pages`로 이관할 때
  `_entities/poke`로 올린다 (실제 사용처가 둘이 되는 시점에 모양을 정한다)

### URL (2026-10-26 변경)
- 그룹마다 키, 값은 ','로 묶는다: `?type=fire,flying&form=alola&gen=1` (nuqs `parseAsArrayOf`, 기본 구분자)
- 키 안은 고른 순서, 키 사이는 그 그룹을 처음 고른 순서 (값 하나인 키라 바꿔도 제자리를 지킨다)
- 값은 DB 열 이름이 아닌 선택지 값 (form은 form_group.identifier)
- 기술 목록(/move)도 같은 형식으로 바꿨다: `?type=fire,grass&damageClass=physical`
- ','는 nuqs가 인코딩하지 않고, 값 안의 ','만 %2C로 바꾼다. 다른 코드가 URL을 %2C로 다시 써도 읽을 때 디코딩되어 결과가 같다
- 버린 안
  - 한 키에 `그룹.값`(facet, `?filter=type.fire_form.alola`, `_shared/lib/facet-param`): 값 단위 고른 순서까지 남기지만
    그 순서를 쓰는 UI(고른 필터 칩 줄)를 만들지 않아 model만 복잡했다. 예전 `?filter=` 링크는 옮기지 않는다
  - 반복 키(`parseAsNativeArrayOf`, `?type=fire&type=flying`): 바꿀 때마다 그 키가 URL 끝으로 옮겨져
    키 순서가 '처음 고른 순서'가 아닌 '최근에 바뀐 순서'가 되고 URL이 클릭마다 흔들린다
- 서버·클라이언트 모두 키마다 같은 값을 읽어 hydration 차이가 없다

### 화면
- 검색창은 입력만. 그 아래 한 줄(모바일·데스크탑 모두, 가로 스크롤):
  `[↻ 초기화] │ [이름 언어] [타입] [모습] [세대]`
- 각 버튼은 md 이상 팝오버, md 미만 시트 (그룹마다 따로, 탭 없음)
- 선택지는 모두 체크박스 (national과 비슷하게). 타입은 아이콘 + 이름 3열, 모습 1열
- 체크박스 목록·그룹 하나짜리 시트는 `_shared/ui/filter`에 추가한다 (기존 타일 방식은 그대로 둔다)
- 이름 언어도 필터 줄에 둔다: 필터와 같은 방식(팝오버·시트)으로 동작하고 초기화를 한 번에 하기 위해

### 초기화
- 검색어 · 이름 언어 · 필터를 한 번에 지운다 (정렬은 결과 줄의 보기 설정이라 두고)
- 하나라도 켜져 있으면 줄 맨 앞에 보인다 (맨 뒤면 모바일에서 스크롤해야 보인다)
- 누르면 버튼이 사라지므로 포커스를 검색 입력창으로
- 검토한 반박: 언어만 되돌리면 영어 검색어가 남아 0건이 된다 → 검색어까지 지워 해결
