# 목록 정렬 UI 통일 (2026-10-19)

## 선택

- **데스크탑 표:** 지금처럼 머리글로 정렬한다 (번호·이름·수치).
  - 처음 누르면 그 기준의 첫 방향: 번호·이름은 오름차순, 수치는 내림차순.
  - 다시 누르면 방향을 뒤집는다.
- **모바일:**
  - 결과 줄에 `[번호순 | 번호 역순]`을 둔다.
    - 지금 상태는 글자 색으로만 표시하고, 상태 설명 글은 따로 두지 않는다.
    - 수치로 정렬 중이면 두 칸 모두 꺼진다.
  - 수치 머리글은 상단에 고정한 한 줄이다. 지금 기준은 화살표 아이콘으로 표시한다.
    - 처음 누르면 높은 순, 다시 누르면 낮은 순.
    - 칸 수: 포켓몬 7, 기술은 위력·명중·PP 3, 특성은 등장 수 1.
  - 이름순 정렬은 없다.
- **동점:** 페이지 기본 순서(번호순)로 정한다. 방향과 관계없다.

## 버린 안

| 안 | 버린 이유 |
|---|---|
| 정렬 메뉴 팝오버 (SortByMenu) | 모바일 팝오버가 UX상 좋지 않음 |
| 바텀시트 (radio·split·matrix) | 기준을 바꿀 때마다 시트를 열어야 함. matrix는 생김새도 별로 |
| 분리 버튼 [기준 ▾][↑↓] | 정렬 중인 수치가 행에서 보이지 않음. 데스크탑과 조작이 다름 |
| 모바일 표 + 가로 스크롤 | VOC 불만 #4 (가로 스크롤) |
| 머리글 두 줄 (번호·이름 줄 + 수치 줄) | 어색함. 머리글 고정 시 높이 부담 |
| 머리글에 번호 칸 (8칸) | 360·375px에서 칸 너비가 44px 미만 |
| 이름순 전체 삭제 | 데스크탑에서 아쉬움 |
| 모바일 세그먼트에 이름순 추가 | 가장 덜 쓰는 기능이 가장 잘 보이는 자리를 차지함. 이름 역순을 표시할 수 없음 |

## 받아들인 대가

- 데스크탑에서 만든 `?sort=name` 링크를 모바일에서 열면, 지금 정렬 상태를 알려주는 표시가 없다.
  - 세그먼트 두 칸이 모두 꺼지고, 강조된 머리글도 없다.
  - [번호순]을 누르면 빠져나올 수 있다. 공유 링크로 이 경우가 생기는 일은 드물다고 판단했다.

## 구현 시 지킬 것

- **세그먼트 강조:** 켜진 칸은 색에 더해 굵기로도 구분한다. 색만으로 상태를 전달하지 않는다 (WCAG 1.4.1).
  - 접근성 속성: `aria-pressed` 또는 `aria-current`.
- **머리글:** 정렬 가능한 머리글에만 ↕ 아이콘을 둔다. `aria-sort`를 단다.
- **화면 폭:** 폭에 따른 차이는 CSS(컨테이너 쿼리)로만 둔다. 화면 폭을 보고 URL 정렬 값을 고치지 않는다.
